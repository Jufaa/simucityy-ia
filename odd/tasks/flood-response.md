Assumptions for this demo (not calibrated physical claims): obstacle rasterization uses cell centers to preserve coarse road corridors, excluding roof rainfall from modeled open-area volume; building exposure samples neighboring open cells. Baseline parks add 15 mm/h infiltration; mitigation parks add 60 mm/h plus six deterministic low-road-node drains of 0.15 m³/s each. Both arms retain existing 15 mm/h background drainage. The default library alarm begins when either arm first blocks a road or exposes a building; the Scene starts unattended and uses this automatic alarm shared by both arms. Walking speed is 1.2 m/s times citizen mobility, reaction delays start at alarm, and mid-edge agents stop in place while that edge is blocked. Simulation speed is explicit and selectable for inspection. These coefficients are local presets, not stored scenario edits.
